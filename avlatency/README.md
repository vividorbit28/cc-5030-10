# avcal · 音画输出延迟校准工具

生成带编号闪光与索引脉冲的校准媒体，经可控录制链（或真实录制）检测事件，
估计呈现延迟。初版固定延迟测量保留为基准；在其之上，连续观测的残差序列
被拟合为可解释分段，区分：

- **稳定时钟速差**：段内斜率（ppm），带 95% 区间；
- **设备重启跳变**：BIC 门控二分分段检出的阶跃，位置与幅度带区间；
- **偶发检测误差**：MAD 稳健剔除，每个剔除点都留有数值依据，可查看，
  绝不静默删除大偏差样本后宣称稳定。

数据不足的区间不给确定校准参数；观测空洞与外推单独标记，外推误差随
距离增大并单独报告。验证使用**独立留出样本**（不参与拟合），页面同时
给出校正前后的留出残差——不会在拟合样本上自证同步。

## 安装

```bash
pip install -r requirements.txt   # numpy + imageio-ffmpeg（自带 ffmpeg）
```

## 延迟校准的图形入口（主入口）

```bash
python -m avcal serve --host 0.0.0.0 --port 8000
# 浏览器打开 http://127.0.0.1:8000/ ，局域网其它设备用 http://<本机IP>:8000/
```

面板流程：

1. **触发校准**：仿真录制链（可设时钟漂移 ppm、跳变时刻/增量、误匹配
   事件、丢弃事件等）或上传真实录制；
2. **测量结果**：基准固定延迟与 95% 区间；
3. **漂移/跳变分析**：分段参数、跳变、剔除记录、独立留出验证、空洞与
   外推说明；**导出播放系统参数（JSON）**；
4. **延迟调整**：由内核结果驱动（失败/未锚定时锁定）。应用修正后，
   播放标记与测量偏移按实际运算更新，异常（修正后偏移超出测量区间）
   由本界面提示；每次应用都记入校准前后独立验证记录。

## 命令行（仅辅助延迟校准）

```bash
python -m avcal generate --out workdir/clip          # 仅生成校准媒体
python -m avcal simulate --out workdir/run [选项]     # 可控录制链 + 校准
python -m avcal analyze --recording cap.mp4 --out workdir/an
```

## 连续观测例（漂移 + 跳变 + 误匹配 + 长缺失）

```bash
python -m avcal simulate --out workdir/observe \
  --events 60 --noise 0.004 \
  --clock-drift-ppm 150 \
  --delay-step 16:0.04 \
  --misalign 30:0.03 \
  --drop 40,41,42,43,44,45 \
  --export-params workdir/observe/playback_params.json
```

预期输出（摘要）：

- 两段有效分段，斜率均约 +150 ppm 且 95% 区间覆盖真值；
- `t≈16 s` 处检出 +40 ms 跳变（设备重启特征），区间覆盖真值；
- 事件 30 被剔除并留有数值依据；事件 40–45 的缺失形成空洞，
  `drift.predict` 在空洞内返回 `gap`、在范围外返回 `extrapolated`；
- 独立留出验证给出校正前→校正后 RMS；
- `playback_params.json` 供播放系统采用——**工具不修改任何真实设备
  设置**，只生成参数文件。

## 估计误差与置信范围的核验

`tests/test_drift.py` 用闪光脉冲与时钟漂移的真值链核验：

- 缓慢线性漂移：单段、斜率区间覆盖真值（音频误差 < 100 ppm，视频区间
  宽但同样覆盖）；
- 突然固定延迟：跳变位置 ±0.75 s 内、幅度区间覆盖真值，两段斜率与 0
  一致（不误判为漂移）；
- 一次误匹配：恰好一条剔除记录，段参数不受影响；
- 事件长时间缺失：空洞被报告，空洞内不给参数，外推区间更宽；
- 置信范围：150 次独立噪声实现的经验覆盖率接近名义 95%。

运行全部测试：

```bash
python -m unittest discover -s tests -v
```
